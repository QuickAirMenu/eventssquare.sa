# design-files — مرجع التصميم المعتمد

> **المالك:** Lynx 🐈 (نظام التصميم) — **المصدر الوحيد للحقيقة البصرية** للمشروع.
> أي تعديل على `homepage.html` يتطلب موافقة القائد ومراجعة Lynx.

## البنية

```
design-files/
├── homepage.html   ← ⭐ التصميم المعتمد للصفحة الرئيسية (لا يُعدل إلا بقرار)
├── img/            ← كل صور التصميم (مُشار إليها بـ img/... من homepage.html)
│   └── (انظر المانيفست أدناه)
└── archive/        ← تجارب ونسخ قديمة (مرجع فقط — غير معتمد)
    ├── aseer-explore-improved.html            (تجربة قسم اكتشف عسير)
    ├── asir-hero-section.html                 (تجربة الـ Hero)
    ├── destination-card-improved-active-inactive.html  (تجربة بطاقة وجهة)
    └── homepage-backup-2026-08-18.html        (نسخة احتياطية من المعتمد)
```

## أقسام homepage.html المعتمدة (بالتسلسل)

1. **Navbar** — ثابت، يتحول لخلفية خضراء داكنة عند التمرير
2. **Hero** — سلايدر 6 شرائح (hero-01 … hero-06) مع بحث
3. **شريط الثقة** — trust-sbc + trust-media
4. **الفئات** — 5 فئات بأيقونات (قصور، معالم، متاحف، إقامة، مطاعم)
5. **الوجهات** — شبكة بطاقات (المرجع: بطاقات الوجهات)
6. **الفعاليات** — بطاقات بتاريخ وشارة حالة
7. **العروض** — بطاقات عروض الشركاء
8. **عالم النكهات** — قسم مطاعم بصري
9. **اكتشف عسير** — المعالم + خريطة Leaflet تفاعلية
10. **التقييمات** — آراء العملاء
11. **النشرة البريدية + التذييل** — أخضر داكن مع سوشيال

## ملاحظات Fox للتنفيذ

- الصور تُنقل لاحقاً إلى `storage/app/public/{listings,events,heroes}/` عند ربطها بالمحتوى الفعلي عبر لوحة التحكم

- نص `alt` عربي وصف obligatoire لكل صورة في التنفيذ النهائي
