## عملية التسجيل في الفعاليات (يدوي، بدون دفع)

### هيكل صفحة الفعالية (نموذج من "جولة مسك"):

```
┌─────────────────────────────────────────┐
│  [صورة البطل + اسم الفعالية]              │
├─────────────────────────────────────────┤
│  التاريخ: من 11 إلى 12 سبتمبر 2024       │
│  رسوم الدخول: مجاناً - حضور             │
│  المدينة: عسير - أبها                   │
├─────────────────────────────────────────┤
│  [وصف الفعالية]                          │
│  [صورة جانبية]                           │
├─────────────────────────────────────────┤
│  سجّلوا الآن:                           │
│  📋 منصة اكس  ← رابط خارجي للحدث         │
│  🏰 برنامج جولة مسك ← رابط خارجي         │
└─────────────────────────────────────────┘
```

### آلية التسجيل الحالية:
- **التسجيل يتم خارج الموقع** — كل فعالية فيها روابط خارجية لمنصات التسجيل
- **لا يوجد نموذج تسجيل داخلي** — يستخدم روابط مثل `eventhub.misk.org.sa`
- **لا يوجد نظام حجز/دفع**
- **Favorites**: المستخدم يسجل إعجابه بالفعالية (simplefavorites_count)

## هيكل المنشور (Event Post)

كل "فعالية" هي منشور (post) بـ Elementor يحتوي:

```json
{
  "الحقول الأساسية": {
    "العنوان": "اسم الفعالية",
    "المحتوى": "(غالباً Elementor فقط)",
    "الصورة البارزة": "_thumbnail_id",
    "صور إضافية ACF": ["featured_image_2", "featured_image_3"]
  },
  "التصنيفات": {
    "events": "نوع الفعالية (ترفيهي، ثقافي...)",
    "country": "المدينة",
    "offers": "العرض/القسم"
  },
  "Elementor Data": {
    "البطل": "صورة + اسم بخط كبير",
    "شريط المعلومات": "التاريخ | السعر | المدينة (3 أعمدة)",
    "المحتوى": "وصف + صورة جانبية (عمودين)",
    "التسجيل": "أيقونات + روابط خارجية + عناوين"
  },
  "SEO": {
    "Rank Math": "focus_keyword, description, title, robots"
  },
  "Favorites": {
    "count": "عدد المفضلة"
  }
}
```

## ملاحظات مهمة للتطوير الجديد

1. **التسجيل خارجي** — نحتاج نضيف نموذج تسجيل داخلي في Laravel
2. **Favorites** — نضيف ميزة المفضلة مع عدد الإعجابات
3. **كل المحتوى Elementor** — نحتاج نستخرج النصوص والصور من JSON
4. **ACF** — حقل "صور إضافية" واحد فقط (صورتين إضافيتين للفعالية)
5. **لا يوجد WooCommerce** — مفيش نظام مبيعات/دفع
