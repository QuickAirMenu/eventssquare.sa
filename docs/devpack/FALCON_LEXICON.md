### 📌 نموذج جاهز — AirMenu (العميل المرجعي)

> هذا النموذج هو المرجع الافتراضي إذا لم يحدد Commander مشروعاً آخر. انسخه لأي عميل جديد وبدّل القيم.

```
اسم المشروع / العميل  : AirMenu
نوع العمل             : B2B (مع نكهة B2C في واجهة الزبون)
القطاع                : مطاعم / كوفيهات / ضيافة
الجمهور المستهدف      : أصحاب المطاعم والكوفيهات السعودية + العملاء النهائيين
اللغة الأساسية        : عربي (RTL) مع إنجليزي عند الحاجة
الأسلوب المطلوب       : ضيافة سعودية أصيلة — دافئ، محترم، رقمي
المنتجات/الخدمات الرئيسية:
  1. iMenu — القائمة الرقمية (تعرض القائمة والطلبات برمز QR)
  2. iCard — بطاقة العمل الرقمية (مشاركة بلمسة واحدة)
  3. لوحة التحكم — إدارة الأصناف والطلبات والإشعارات
مصطلحات خاصة بالمشروع يجب استخدامها:
  - iMenu تبقى بالإنجليزية دائماً: "قائمة iMenu الرقمية"
  - iCard تبقى بالإنجليزية دائماً: "بطاقة iCard الرقمية"
  - لوحة التحكم (لا "داشبورد") | الأصناف (لا "الآيتامز")
  - رقم الجوال بالصيغة الدولية دائماً: +966XXXXXXXXX
مصطلحات يجب تجنبها في هذا المشروع:
  - آي منيو / الآي كارد / القائمة الالكترونية / البيل / الأوردر
```

## 6️⃣ قوالب المحتوى الجاهزة — Content Templates

### زر / CTA
```
صيغة: فعل أمر + وصف الفائدة
✅ ابدأ تجربتك المجانية
✅ احصل على عرضك الآن
✅ جرّب مجاناً لمدة 14 يوم
✅ تواصل مع فريقنا
❌ إرسال / موافق / اضغط هنا
```

### عنوان صفحة (H1)
```
صيغة: فعل + نتيجة للمستخدم
✅ حوّل [X] إلى [نتيجة مميزة]
✅ [X] أسرع وأسهل من أي وقت
✅ ابنِ [X] في دقائق — بدون خبرة تقنية
```

### وصف ميزة
```
السطر 1: ما تفعله الميزة (فعل + نتيجة)
السطر 2: كيف تعمل (جملة واحدة بسيطة)
السطر 3: الميزة التنافسية أو الفارق
```

### رسالة خطأ
```
صيغة: ما حدث + كيف تصلحه (لا تلم المستخدم)
✅ رقم الجوال غير مكتمل — أدخله بالصيغة: +966XXXXXXXXX
✅ كلمة المرور قصيرة — يجب أن تكون 8 أحرف على الأقل
❌ خطأ في الإدخال
❌ حدث خطأ، حاول مجدداً
```

### رسالة نجاح
```
صيغة: ما تم + الخطوة التالية
✅ تم الحفظ بنجاح! يمكنك مشاركة الرابط الآن
✅ تم إرسال الطلب — سنتواصل معك خلال 24 ساعة
❌ تمت العملية بنجاح
```

### حالة فارغة (Empty State)
```
صيغة: لا يوجد X بعد — ابدأ بـ Y
✅ لا توجد سجلات بعد — أضف أول سجل الآن
✅ قائمتك فارغة — ابدأ بإضافة أول عنصر
❌ لا يوجد شيء هنا
```

### رسالة SMS (لا تتجاوز ١٦٠ حرفاً)
```
[اسم الخدمة]: {الرسالة الرئيسية}. {إجراء أو رابط}. للاستفسار: {رقم}
مثال (تأكيد حجز): قائمة iMenu: تم تأكيد حجزك ليوم {التاريخ} الساعة {الوقت}.
للتفاصيل: {الرابط} | للاستفسار: +966XXXXXXXXX
```

### رسالة WhatsApp
```
مرحباً {الاسم} 👋

{الرسالة الرئيسية — جملة أو جملتان}

{الخطوة التالية أو الإجراء}

فريق {اسم الشركة}
مثال: مرحباً {الاسم} 👋 / تم استلام طلبك رقم #{الرقم} بنجاح. / سنوافيك بالتأكيد قريباً. / فريق AirMenu
```

### عبارات تسويقية — أمثلة جاهزة (مشاريع الضيافة)
```
للمطاعم (iMenu):
- اعرض قائمتك رقمية… بدون طباعة، بدون انتظار.
- امسح الرمز وشاهد القائمة كاملة على جوالك.
- حدّث أسعارك وأصنافك… بضغطة زر، من أي مكان.

للبطاقات (iCard):
- بطاقة عملك الرقمية… في جيب كل من يقابلك.
- شارك بياناتك بلمسة واحدة — بدون طباعة، بدون بطاقات ضائعة.

للمنصة (AirMenu):
- من القائمة إلى بطاقة العمل… كل شيء رقمي في مكان واحد.
- مستقبل الضيافة يبدأ برقمي.
```

### موضوع البريد الإلكتروني
```
صيغة: [فعل/حدث] + [الموضوع] — [اسم الخدمة]
✅ تأكيد طلبك — [اسم الشركة]
✅ تحديث مهم على حسابك في [اسم الخدمة]
✅ [الاسم]، موعدك غداً الساعة {الوقت}
❌ Notification / تنبيه / رسالة من النظام
```

### وصف الشركة / About (٣ أسطر)
```
السطر 1: ماذا نفعل + لمن
السطر 2: كيف نفعله بشكل مختلف
السطر 3: النتيجة / القيمة للعميل
```

## 7️⃣ قواعد الإملاء والتنسيق — Writing Rules

### الهمزة
```
✅ أعمال / إنشاء / آمن / اتصال / أُنجز
قاعدة: همزة القطع في بداية الكلمة المضمومة → أُ
       همزة القطع في الفعل الماضي الرباعي → أَ (أرسل، أضاف)
```

### التاء المربوطة والمفتوحة
```
✅ منصة / خدمة / قائمة    (مفرد = تاء مربوطة)
✅ منصات / خدمات / قوائم  (جمع = تاء مفتوحة)
```

### الأرقام
```
في النصوص العربية الرسمية:  ٥٠٠ عميل / ١٥ دقيقة
في البيانات والكود:          500 / 15
الأسعار:                    ١٩٩ ريال أو 199 ريال (كلاهما مقبول)
النسب المئوية:              ٩٨٪ رضا العملاء
```

### أرقام الجوال (سعودية / خليجية)
```
الدائماً بالصيغة الدولية:  +966XXXXXXXXX — لا تُحذف +966 أبداً
مثال على الصحيح:           +966512345678
خطأ شائع:                  0512345678 / +966 5 12345678 (بمسافات)
```

### علامات الترقيم
```
الفاصلة العربية:  ،  (وليس ,)
في واجهات المستخدم: يُقبل استخدام , الإنجليزية
النقطة: . (الإنجليزية مقبولة في جميع السياقات)
الاستفهام: ؟ في النصوص العربية
```

### التشكيل
```
لا تشكيل في واجهات المستخدم — يُبطئ القراءة
التشكيل فقط في: محتوى تعليمي / عناوين تمييزية كبيرة جداً
```

### الشدة والمد
```
✅ مُصمَّم / مُخصَّص / مُتكامل (عند الحاجة للوضوح)
✅ آمن / آلية / آخر (ألف المد)
```

### العادات السعودية — التاريخ والعملة
```
العملة: ريال سعودي / ١٩٩ ريالاً — ولا "رياله" في النصوص الرسمية
التاريخ الهجري: يُستخدم عند الاقتضاء الثقافي → ١٥/٠٩/١٤٤٦هـ
التاريخ الميلادي: 15/09/2026 — معياري للأنظمة
الصيغة الدولية للجوال إلزامية في كل النماذج: +966XXXXXXXXX
```
